# 💰 SpendWise — Student Expense Tracker

A modern and responsive web application designed to help students track daily expenses, manage budgets, monitor savings goals, and understand their spending habits.

## 🚀 Live Demo

Coming soon.

## ✨ Features

- 📊 Track total expenses and number of expenses
- 💰 Calculate average spending
- 📝 Add and manage daily expenses
- 🏷️ Organize expenses by categories
- 📅 View expenses by time period
- 🎯 Set monthly budgets and savings goals
- 📈 Visualize spending using category-based charts
- 📋 Get category-wise spending insights
- 📱 Responsive design for mobile and desktop
- 🌙 Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## 🎓 Purpose

SpendWise was developed as a student web development project to provide a simple and practical way for students to manage their personal expenses and understand their spending patterns.
